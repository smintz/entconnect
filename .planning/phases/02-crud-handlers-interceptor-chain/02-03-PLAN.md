> privacy-aware interceptor chain — no hand-written handler code, no ent client leakage.

<objective>
Widen the proven slice to the read-many path: **a generated List handler that pages by keyset, not
offset.** A first page comes back with an opaque `next_page_token`; feeding that token to a second
call continues exactly where the first stopped.

text and ROADMAP Success Criterion 2 currently attribute keyset paging to a native ent method that

reinterpreting it. Task 1 retires the claim on the record before any code depends on the
reinterpretation.

ordering fingerprint, the List generator emitting hand-built keyset predicates over ent's real
per-field comparison operators, and a fixture app whose tests cover the tie, empty, exact-boundary,
and fingerprint-mismatch cases.
</objective>
