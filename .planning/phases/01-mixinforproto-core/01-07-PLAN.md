repository contradicts itself, and 01-03-PLAN.md's own declared key link does not function.

```
Failure: plugin protoc-gen-go: buf.build/gen/go/bufbuild/protovalidate/protocolbuffers/go/buf/validate/validate.pb.go: generated file does not match prefix "github.com/smintz/entconnect/mixinforproto"
```

drift again, which is exactly how this happened. This plan collapses them to one shared script

makes the gate runnable locally with one command, and then PROVES the gate detects staleness by
deliberately breaking the tree three ways and observing the verdict.

Purpose: a staleness gate that has never been observed failing is indistinguishable from no gate.
The verification report could not run this job at all; this plan makes its detection power an
executed, recorded fact.

Output: one canonical generation invocation, one gate, three recorded detection proofs, and a
`go`-directive pin assertion that encodes a hazard currently recorded only in SUMMARY prose.

1. **`buf` v1.72.0 and `protoc-gen-go` v1.36.11 ARE installed** at `$(go env GOPATH)/bin`, but are

   recorded "buf is not installed in this environment"; that was a `PATH` fact, not a machine fact,
   which is why gap 4 could not be executed during verification.)
2. **The gate design in this plan was rehearsed at plan time and works.** Copying only the working
   tree's `proto/` directory into an empty temp root and running the scoped generation from there
   produces `<root>/mixinforproto/internal/gen/mixinforprototestv1/*.pb.go`, and
   `diff -rq mixinforproto/internal/gen <root>/mixinforproto/internal/gen` reported no differences
   against the committed tree. `buf.gen.yaml`'s `out: ../mixinforproto` is relative to `proto/`, so
   the output lands correctly under the temp root with no extra plumbing.
3. **Do not keep the `git archive HEAD | tar -x` step.** Beyond WR-03's orphan blind spot, archiving
   `HEAD` means the gate silently ignores working-tree proto edits, so a developer cannot rehearse
   it before committing. Copying the working tree's `proto/` into an EMPTY output root subsumes both
   `git archive` and WR-03's `rm -rf`, and is what fact 2 rehearsed.
