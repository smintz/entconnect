## Reconciliation applied in this plan

- **R4 — D-23's golden-assertion shape (binds Task 2).** CONTEXT.md D-23 says to "marshal each
  derived field's `Descriptor()` into a stable, key-sorted document". RESEARCH.md Correction 2
  fetched the real `field.Descriptor` struct and found it carries `Validators []any` (live closures)
  and `Err error` — neither is JSON-marshalable, so `json.Marshal` on the raw descriptor **errors**
  the moment any Tier 1 rule attaches a validator. Verified at plan time: `field.String("email").MaxLen(64)`
  already yields `len(Descriptor().Validators) == 1`. **Resolution: golden tests assert a
  hand-written serializable projection struct, never the raw descriptor.** D-23's intent (stable,
  key-sorted, goldie-compared) is preserved; only the marshal target changes.
- **R1 (inherited):** no cel-go dependency is added by this plan.

## Flagged assumptions (edge probe — unclassified rows carried forward)

The edge probe returned `unclassified` for all six requirements below; per the fallback protocol
they stay **unresolved** and are surfaced here rather than auto-resolved with a backstop. Each is a
mapping-table decision with no data-shape edge, so the assumption is "the mapping table in
`mixinforproto.md` §5 is normative and complete for Phase 1":

- **MIX-02 (unclassified):** assumption — proto scalar kinds map one-to-one onto the same-width ent
  builder (`int32`→`field.Int32`, `uint64`→`field.Uint64`, `bytes`→`field.Bytes`, and so on), with
  no widening. `sfixed`/`sint`/`fixed` variants map to the same width as their plain counterpart.
- **MIX-03 (unclassified):** assumption — enum values use the proto enum value **names** as declared,
  with no case transformation and no stripping of a leading `ENUM_NAME_` prefix.
- **MIX-04 (unclassified):** assumption — only `Timestamp`, `Struct`, `Value` map; `FieldMask` and
  `Duration` are skipped. `Duration` skipping is deliberate (MIX2-04 is v2), not an oversight.
- **MIX-05 (unclassified):** assumption — `Default(zero)` on non-optional proto3 scalars is correct
  by wire semantics and is documented, not fixed, in Phase 1 (D-26). This is the design's
  self-declared sharpest edge.
- **MIX-06 (unclassified):** assumption — a scalar-valued map becomes one `field.JSON` typed as a Go
  map of the key/value Go types; map **constraints** are recorded as residual, not enforced (Phase 3).
- **MIX-13 (unclassified):** assumption — "deterministic order" means proto declaration order
  (descriptor index), not alphabetical. Declaration order is what `protoreflect.FieldDescriptors`
  yields natively and is the order a contract author reads.
