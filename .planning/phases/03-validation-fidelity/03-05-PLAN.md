<objective>
Close the phase: opt-in Create-time enforcement of message-level rules with a schema-load gate
against phantom cross-field comparisons, a conformance corpus that makes an unexercised
constraint class a named failure, and the differential sweep that keeps D-07's hybrid honest.

Purpose: VAL-08 keeps cross-field rules boundary-only by default because
`mixinforproto.md` §4.3's literal "constructs an `M` from mutation fields" would leave excluded
fields at their proto3 zero, so a rule like `this.discount <= this.subtotal` would return a
verdict — pass or fail — computed from data that was never real. D-10 makes that a schema-load
panic instead. PIPE-05 then turns "the corpus happens to avoid this shape" from a silent
condition into a detectable one, which is exactly the root cause Phase 1's gap-closure wave 3
existed to close. PIPE-06 is not a closing formality: 03-CONTEXT.md D-07 states plainly that the
differential harness is the mechanism that keeps the hybrid-evaluator choice safe.

Output: `WithMessageRules(OnCreate)` and its field-reference walk; corpus and coverage guards
extended to every protovalidate constraint class; and a deterministically seeded, driverless
differential sweep asserting `protovalidate verdict == ent mutation verdict` for field-scoped
rules across every corpus message.
</objective>
