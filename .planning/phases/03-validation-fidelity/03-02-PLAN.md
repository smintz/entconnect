<objective>
Build the reverse half of `fieldmap.go`'s conversion table — ent Go value back to
`protoreflect.Value` — for every derivation kind, so the mutation hook can hand real mutation
data to protovalidate's own evaluator and to the local CEL environment with protovalidate
semantics intact.

Purpose: D-05 explicitly rejects binding ent's Go values directly through a cel-go type adapter,
because a rule written against `google.protobuf.Timestamp` expects `.seconds` and a `time.Time`
has no such field — the moment that breaks, protovalidate semantics stop holding, which is the
one property this phase exists to guarantee. 03-CONTEXT.md names the JSON-to-`dynamicpb` leg as
one of the phase's two genuine risk concentrations and requires it be its own task with its own
tests, not a bullet inside a larger handler task.

Output: a complete `reverse.go` keyed on the same derivation-class strings `fieldmap.go` writes
into `SourceField.Kind`; per-kind round-trip tests over new corpus fixtures; the D-12 fail-closed
error contract proven by test; D-09's boundary-only provenance recorded on `SourceMessage` for
every contract rule that lands on a field ent does not have; and the `MixedFieldRules` corpus
fixture plan 03-03 needs to settle the D-07/D-08 convergence.
</objective>
